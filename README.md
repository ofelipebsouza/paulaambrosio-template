# Paula Ambrosio Interiors

Premium editorial website for Paula Ambrosio Interiors — luxury interior design in Miami and South Florida.

**Stack:** Astro · TypeScript · Tailwind CSS v4 · MDX content collections · Vercel

## Commands

| Command           | Action                                    |
| ----------------- | ----------------------------------------- |
| `npm run dev`     | Local dev server at `localhost:4321`      |
| `npm run build`   | Production build to `./dist/`, then the post-build guard |
| `npm run check`   | Post-build guard on its own (`dist/`)     |
| `npm run preview` | Preview the production build locally      |
| `npm run lint`    | Typecheck (`astro check`)                 |

`npm run build` fails if the output contains an insecure form action, a plain-http
reference, more than one `<h1>`, a canonical that does not match the served URL, or
a broken internal link. That guard is what keeps Best Practices at 100 — a
`<form action="mailto:…">` on an HTTPS page is flagged by Chrome as insecure form
submission and drops the Lighthouse category to 77.

## Architecture

```
src/
├── config.ts              # Brand entity, contact, canonical URLs, nav (single source of truth)
├── lib/seo.ts             # Centralized SEO + JSON-LD schema builders
├── layouts/Layout.astro   # <head>: meta, canonical, OG/Twitter, fonts, entity schema graph
├── components/
│   ├── Header.astro / Footer.astro
│   ├── projects/ProjectGrid.astro
│   └── ui/                # Breadcrumbs, CtaBanner, FAQ (zero-JS details/summary)
├── content/
│   ├── projects/          # Case studies (MDX)
│   ├── journal/           # Articles (MDX)
│   ├── services/          # Service pages (MDX)
│   └── locations/         # Location pages (MDX)
├── pages/                 # Static routes; /projects /services /locations /journal + [slug]
└── styles/global.css      # Design tokens (@theme) + editorial primitives
```

- **Static output.** No server runtime. Deployed to Vercel via GitHub.
- **Content collections** with strict Zod schemas (`src/content.config.ts`) — invalid frontmatter fails the build.
- **SEO** is centralized: pages pass `title/description/canonical/ogImage` to `Layout.astro` and emit schemas from `src/lib/seo.ts` (Organization, Person, WebSite, WebPage, BreadcrumbList, Article, Service, FAQPage).
- **Redirects** from the previous Framer URL structure live in `vercel.json` (301s).
- **Sitemap** is generated by `@astrojs/sitemap` (`/sitemap-index.xml`); `public/robots.txt` points to it.
- **Fonts** are self-hosted in `public/fonts/` (preloaded woff2, no render-blocking third-party requests).

## Editing content (agent-safe)

All content lives in `src/content/**` as MDX with predictable frontmatter. The Zod
schemas are the contract — read them before writing content. Frontmatter fields:
`title`, `draft`, `featuredImage`, `imageAlt`, `seoTitle`, `seoDescription`, plus
collection-specific fields (`faqs`, `relatedServices`, `relatedLocations`,
`relatedProjects`, `gallery`, `services`, …). Set `draft: true` to keep a file out
of the build and sitemap.

Agent workflow (Hermes-compatible): branch → edit/create MDX → `npm run build`
(validates schemas + links) → commit → PR → Vercel preview → merge to `main`.

## Environment variables

| Variable                | Purpose                                              |
| ----------------------- | ---------------------------------------------------- |
| `CONTACT_FORM_ENDPOINT` | Optional. An **https** URL that receives the contact form (CRM, email API, webhook) and answers 2xx once the lead is stored. Unset — or set to anything that is not https — the form composes the inquiry into a `mailto:` URL and opens the visitor's mail client. |

No secrets belong in the repository.

## URL contract

The site is served with `trailingSlash: true` (see `vercel.json`), so every route
ends with a slash: `/about/`, `/projects/home-ka/`. Canonicals, `og:url`, the XML
sitemap and all internal links use that exact form — anything else costs a 308
redirect. `src/config.ts` owns the helpers (`serviceUrl`, `locationUrl`,
`projectUrl`, `absoluteUrl`) and `npm run build` verifies it.

The canonical origin is `https://www.paulaambrosio.com` (`astro.config.mjs` `site`
and `SITE.url` in `src/config.ts`). The apex domain redirects to it in
`vercel.json`.
